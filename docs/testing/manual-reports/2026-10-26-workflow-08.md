# Verification: Start activity during scheduled session

- Date: 2026-10-26 (Asia/Taipei)
- Expected behavior: An admin can mark an incoming/scheduled activity Ongoing only while one of its scheduled session dates is active. - Scope: `includes/activity-schedule.php`, `pages/shared/activity-detail.php`, and `pages/shared/activities.php`.
